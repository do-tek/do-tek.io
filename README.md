# Do-Tek DNS

Веб-сайт платформы превентивной DNS-безопасности Do-Tek.

Do-Tek защищает корпоративные и частные сети от фишинга, вредоносных доменов,
C2-инфраструктуры, DNS-туннелей и других угроз на уровне DNS.

## О платформе

Do-Tek объединяет защищённый DNS-резолвинг, фильтрацию, мониторинг,
аналитику и интеграцию с корпоративной инфраструктурой.

Основные возможности:

- DNS, DNS-over-HTTPS и DNS-over-TLS;
- блокировка фишинга, malware и C2-инфраструктуры;
- обнаружение DNS-туннелей и DGA-доменов;
- индивидуальные политики фильтрации;
- интеграция с LDAP и Active Directory;
- поддержка внутренних DNS-зон;
- метрики Prometheus и визуализация Grafana;
- передача событий в SIEM;
- уведомления через Telegram, Teams, Slack и Email;
- облачное и on-premise-развёртывание.

## Для бизнеса

Do-Tek может быть встроен в существующую инфраструктуру без полной
перестройки DNS-контура.

Доступны:

- пилотное внедрение;
- on-premise-развёртывание;
- размещение в облачной инфраструктуре;
- адаптация политик под требования заказчика;
- интеграция с существующими средствами мониторинга и ИБ;
- техническое сопровождение и обучение.

## Технологическая база

В основе Do-Tek используются технологии и компоненты экосистемы OpenBLD.

Дополнительная информация:

- Do-Tek: https://do-tek.io/
- OpenBLD: https://openbld.net/

## Note on Service Worker

`sw.js` оставлен как self-destruct worker для удаления старой PWA-регистрации и кэшей. Сам сайт service worker не регистрирует.
